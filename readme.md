📊 Social Media Campaign Analysis Dashboard

📌 Overview

This project is a Social Media Campaign Analysis Dashboard created to understand how different campaigns perform across platforms.
It helps track reach, engagement, impressions, clicks, spend, CTR, and conversions in a simple, visual, and meaningful way.
🎯 Objectives

Analyze multi-platform campaign performance

Identify high-engagement campaigns

Compare ad spend vs results

Understand audience interaction

Improve future marketing strategies



---

🗂️ Dataset Details

The dataset includes the following columns:

Campaign ID

Platform (Instagram, Facebook, YouTube, LinkedIn, etc.)

Date

Impressions

Reach

Engagement

Clicks

CTR (%)

CPC

Conversions

Spend🛠 Tools Used

Power BI / Excel (Dashboard)

Excel / Python (Data Cleaning)

GitHub (Documentation)
